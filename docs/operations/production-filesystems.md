# Production read-only filesystem policy

Production containers use `read_only: true` wherever the application does not need to persist runtime changes. Writable paths are explicit.

| Service | Read-only root | Writable paths | Purpose |
|---|---|---|---|
| backend | yes | `/tmp` as tmpfs | bounded temporary upload/runtime data only; business data is in PostgreSQL and MinIO |
| frontend | yes | `/tmp`, `/var/cache/nginx`, `/var/run` as tmpfs | nginx PID and temporary cache files |
| PostgreSQL | yes | `/var/lib/postgresql/data` volume; `/var/run/postgresql` and `/tmp` as tmpfs | database files, Unix socket, temporary query files |
| MinIO | yes | `/data` volume; `/tmp` as tmpfs | private bucket objects and bounded temporary files |
| Caddy | yes | `/data` and `/config` volumes; `/tmp` as tmpfs | ACME certificates, OCSP state and Caddy runtime configuration |
| backup-service | yes | backup staging path and Restic cache as dedicated volumes/tmpfs | encrypted snapshot staging and cache; added in Stage 5D |
| migration-service | yes | `/tmp` as tmpfs | Prisma engine temporary files; migrations and application image remain immutable |

Do not add a writable bind mount to backend or frontend. Any new writable path must be documented here with its owner, retention and backup policy.

## MinIO public perimeter

- `files.<domain>` proxies only MinIO S3 API port `9000`.
- MinIO Console port `9001` is not started and is never published.
- The bucket remains private and anonymous access is set to `none`.
- MinIO CORS allows only `https://<domain>`.
- Browser users never receive MinIO access or secret keys.
- Upload, preview and download use short-lived presigned URLs generated by backend.
- Public bucket listing is denied by the private bucket policy; Caddy does not expose credentials or a console endpoint.

## HSTS activation

The default production example mounts `ops/caddy/hsts.disabled`. After the real domain serves a valid certificate and HTTPS has been checked from outside the production network, set:

```dotenv
CADDY_HSTS_FILE=./ops/caddy/hsts.enabled
```

Then recreate only Caddy. Do not enable HSTS before the certificate, DNS and rollback path are confirmed.
